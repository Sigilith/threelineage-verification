## TraceGuard and TICP-1 distinction

The TraceGuard implementation in this public verification package is a local SHA-256 hash-chained ledger. It detects record modification when the historical chain is not coherently rewritten, but does not by itself establish external immutability or protect against full rewriting of the ledger and locally trusted state by a privileged host attacker.

ThreeLineage has separately developed TICP-1, a checkpoint-integrity protocol using domain-separated SHA-256 checkpoint hashes, detached Ed25519 signatures, previous-checkpoint linkage, sequence continuity and support for external anchor receipts. Its local implementation has a recorded result of 18/18 tests passing. This is historical local test evidence, not independent assessment. Independent signing, live externally maintained rollback-resistant anchoring and integration into this candidate's execution-verification path remain outstanding.

## Compatibility and scope

This candidate extends the V1.0.0 verification repository. It does not rewrite V1.0.0 historical evidence or publish the complete integrated ThreeLineage runtime.

The OT scenario uses synthetic telemetry and remains non-actuating. It does not perform physical control, establish a safety case, or claim IEC 62443 certification. The CI results are internal automated verification, not independent assessment.

No V1.1.0 tag or release should be created until the final pull request review, final candidate commit, refreshed manifest and full release gate are complete.
