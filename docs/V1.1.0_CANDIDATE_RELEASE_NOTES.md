# ThreeLineage Verification V1.1.0 — Candidate Release Notes

Status: Development candidate. V1.0.0 remains the latest published release.

## Proposed title

**Autonomy Under Pressure**

## Candidate additions

- An integrated deterministic scenario for the existing Sigilith autonomy-pressure engine and non-actuating OT boundary adapter.
- Assertions for full permission, proportional attenuation, HOLD_ESCALATE and FAIL_CLOSED outcomes, including the effective permitted delta.
- Delegation cap and delegation-escalation scenarios using the existing Ed25519 delegation verifier.
- Guardian single-use permit replay rejection and TraceGuard ledger tamper detection.
- A dedicated GitHub Actions workflow running the complete existing release gate.
- Candidate scenario guide and CI verification report.

## Compatibility and scope

This candidate extends the V1.0.0 verification repository. It does not rewrite V1.0.0 historical evidence or publish the complete integrated ThreeLineage runtime.

The OT scenario uses synthetic telemetry and remains non-actuating. It does not perform physical control, establish a safety case, or claim IEC 62443 certification. The CI results are internal automated verification, not independent assessment.

No V1.1.0 tag or release should be created until the final pull request review, final candidate commit, manifest verification and full release gate are complete.
