## TraceGuard integrity boundary

The TraceGuard implementation in this public verification repository is a local SHA-256 hash-chained ledger. It validates sequence, previous-hash links and record hashes. It detects record modification when the historical chain is not coherently rewritten; it does not, by itself, provide external immutability or resist an attacker able to rewrite the complete ledger and all trusted state on the same host.

ThreeLineage has separately developed TICP-1, a checkpoint-integrity protocol using domain-separated SHA-256 checkpoint hashes, detached Ed25519 signatures, previous-checkpoint linkage, sequence continuity and support for external anchor receipts. The recorded local implementation reports 18/18 tests passing. This is historical local project evidence, not an independent assessment or a test run in this repository.

Independent signing infrastructure, a live externally maintained rollback-resistant anchor and integration into the V1.1.0 execution-verification path have not yet been demonstrated. The candidate does not claim that the public TraceGuard ledger alone resists full host compromise.
